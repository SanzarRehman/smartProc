# RRF HTML Generation & PDF Conversion

## Overview
The RRF system now generates documents in **HTML format** using the LLM, which provides several benefits:
1. **Better Formatting**: Professional styling with CSS
2. **Easy Preview**: View directly in browser
3. **Better PDF**: HTML-to-PDF conversion produces cleaner results
4. **Flexibility**: Can be rendered anywhere that supports HTML

## How It Works

### 1. Generation Process
```
Email → EmailProcessingService → RRFService.generateAndSaveRRF()
         ↓
    Builds HTML-specific prompt → GeminiAIService.generateRRFDocument()
         ↓
    LLM generates HTML → Saves to database as rrfContent
```

### 2. LLM Prompt Changes
The prompt now explicitly requests HTML format with:
- Professional header with inline CSS styling
- HTML tables for structured data
- Proper sections using `<div>` and `<section>` tags
- Signature blocks as HTML tables
- Responsive and print-ready styling

### 3. PDF Generation
```
PDF Request → PDFGenerationService.generateRRFPDF()
              ↓
         Detects if content is HTML (starts with '<')
              ↓
         YES → HtmlConverter.convertToPdf() (iText html2pdf)
              ↓
         NO → createStructuredPdf() (Fallback)
```

## API Endpoints

### Get RRF as JSON
```bash
curl http://localhost:8080/api/rrf/PO-2025-0248-BUE
```

### View RRF as HTML (in Browser) ⭐ NEW
```bash
# Open in browser to see formatted HTML
open http://localhost:8080/api/rrf/PO-2025-0248-BUE/html
```
**Response:** Rendered HTML page with professional styling

### Get RRF Content (Raw)
```bash
curl http://localhost:8080/api/rrf/PO-2025-0248-BUE/content
```
**Response:** Raw HTML source code

### Download as PDF
```bash
curl http://localhost:8080/api/rrf/PO-2025-0248-BUE/pdf --output rrf.pdf
```
**Response:** PDF file generated from HTML

## Database Changes Required

Since the content format changed from plain text to HTML, you need to:

1. **Run the database fix** (if not already done):
```bash
psql -U postgres -d procurement_db -f fix-rrf-lob-issue.sql
```

2. **Delete old RRF records** (they have plain text, not HTML):
```sql
DELETE FROM request_for_requisition;
```

3. **Rebuild and restart**:
```bash
./gradlew clean build
./gradlew bootRun
```

## Troubleshooting

### Issue: PDF looks plain
**Solution**: Check if HTML is being generated. View `/html` endpoint first.

### Issue: HTML has markdown code blocks (```html)
**Solution**: The `cleanHtmlContent()` method automatically removes these.

### Issue: Old RRFs show as plain text
**Solution**: Delete old records and regenerate:
```sql
DELETE FROM request_for_requisition WHERE rrf_content NOT LIKE '<%';
```

### Issue: PDF generation fails
**Solution**: The system automatically falls back to structured PDF generation.
